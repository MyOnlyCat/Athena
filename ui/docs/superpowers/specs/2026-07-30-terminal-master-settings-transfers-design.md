# Athena-Node 终端、主节点配置与文件传输增量设计

## 背景与目标

本次增量解决网页 SSH 输入后会话关闭、远程文件无法下载的问题，并补充以下能力：

- 进入网页 SSH 后默认使用应用内全屏，隐藏主导航和顶部栏，可退出全屏恢复控制台布局。
- 管理员可在页面配置主节点协议、IP 或域名、端口和节点 Token。
- 远程文件支持输入绝对路径并跳转。
- 文件上传支持多选、进度、任务队列和页面内后台传输。
- 离开 SSH 页面或切换远程主机时取消仍未完成的上传。
- 完成实现后同步更新项目文档并提交代码。

## 范围边界

- “全屏”指 Athena 应用内全屏，不调用浏览器 Fullscreen API，不触发浏览器权限提示。
- 批量上传只支持多选文件，不支持选择本地文件夹或保留本地目录结构。
- 上传任务只在当前 SSH 页面存活，不跨路由、刷新或 API 重启恢复。
- 离开 SSH 页面或切换远程主机时立即取消排队中和传输中的任务。
- 主节点 Token 只写不读；API 和 UI 均不显示已保存 Token 的明文。

## 页面与交互

### 网页 SSH 全屏

`AppShell` 根据终端路由和终端页面状态切换布局。进入 `/terminal` 时默认隐藏左侧栏、顶部栏和常规内容边距，终端三栏占满视口。终端工具栏显示“退出全屏”按钮；退出后恢复侧栏、顶部栏和普通内容区域，并提供“进入全屏”按钮。

全屏状态只属于当前终端页面。离开页面后清除，重新进入时再次默认全屏。

### 主节点配置

新增“主节点配置”菜单和页面，包含：

- 协议：`http` 或 `https`。
- IP 或域名。
- 端口：1–65535。
- 节点 Token：密码输入框；读取时为空，空白保存表示保留现有 Token。
- 当前状态：未配置、连接中、在线或异常。
- 操作：测试连接、保存并应用。

保存时先校验格式并对目标主节点执行签名连接测试。测试通过后才持久化并切换运行中的主节点客户端；测试或切换失败时继续使用旧配置。

### 远程文件

文件面板顶部使用可编辑路径输入框。用户可输入绝对 POSIX 路径并按 Enter 跳转，也可使用根目录和父目录操作。加载失败时保留原路径和原文件列表。

下载使用带 JWT 的流式 HTTP 请求。前端从响应头解析文件名，创建下载对象并在浏览器接管下载后延迟释放对象 URL。下载错误在文件面板中显示，不产生空文件。

上传选择器允许多选。每个文件创建独立任务，默认最多 3 个并发，任务状态包括：

- `queued`
- `uploading`
- `succeeded`
- `failed`
- `cancelled`

任务面板显示总任务进度、单文件字节进度、目标路径、状态，以及取消单项和取消全部操作。每个任务的目标目录在选择文件时固定，随后浏览目录不改变已排队任务的目标。

## 后端设计

### SSH 终端桥接

AsyncSSH 终端以 `encoding=None` 创建，输入和输出均保持字节类型。浏览器输入的 Base64 数据解码为字节后直接写入远程 stdin，不再转换为字符串。桥接任一方向异常时：

1. 取消另一个桥接任务。
2. 尽力向 WebSocket 返回结构化终端错误。
3. 关闭远程进程和 SSH 连接。
4. 释放用户终端会话计数。

正常的远端 EOF 仍关闭会话，但前端区分正常关闭与连接错误。

### 文件传输

下载保持 `StreamingResponse`，远程 SFTP 连接在流结束、客户端取消或异常时均关闭。响应使用兼容非 ASCII 文件名的 `Content-Disposition`。

上传继续由单个 HTTP 请求流式写入 SFTP，不把文件暂存到子节点磁盘。前端通过 Axios 上传进度事件更新任务，并用每个任务独立的 `AbortController` 取消请求。API 保留单文件大小上限。

### 主节点配置与运行时切换

SQLite 新增单例主节点配置记录，保存：

- 协议。
- 主机。
- 端口。
- Fernet 加密后的节点 Token。
- 更新时间。

数据库配置优先于环境变量；环境变量只作为数据库尚无记录时的首次启动默认值。

新增主节点配置服务负责验证、脱敏读取和加密保存。新增运行时管理器独占当前 `MasterClient`、心跳/任务轮询循环和关闭流程。应用启动、保存新配置和应用关闭都通过该管理器执行，避免多套循环并存。

本地管理 API：

- `GET /api/v1/master-settings`：返回协议、主机、端口、`has_token` 和运行状态。
- `POST /api/v1/master-settings/test`：使用请求中的地址和 Token 测试签名连接；Token 为空时使用已保存 Token。
- `PUT /api/v1/master-settings`：测试、保存并立即应用；Token 为空时保留已保存值。

只有已登录管理员可访问。错误使用现有统一结构，不在日志或错误详情中包含 Token。

## 错误处理

- 无效路径在请求发出前阻止；远端目录不存在或无权限时保留当前列表并显示中文错误。
- 单个上传失败不阻塞队列中其他文件；取消与失败分开显示。
- 离开页面和切换主机触发的取消不弹出错误通知。
- SSH 输入协议错误、远端通道错误和网络断开使用不同的前端状态文案。
- 新主节点配置测试失败时不覆盖数据库配置，不停止现有工作循环。
- 已保存 Token 永不通过读取接口返回；日志遮蔽请求中的 Token。

## 测试与验收

后端自动化测试覆盖：

- 二进制终端收到输入字节后保持桥接，不因类型错误关闭。
- 终端 EOF、WebSocket 断开和桥接异常均清理资源。
- 下载内容、文件名、客户端取消和 SFTP 关闭。
- 主节点配置验证、Token 加密/脱敏、空 Token 保留。
- 新配置测试失败时旧配置继续运行。
- 配置成功后旧循环停止且只启动一个新循环。

前端自动化测试覆盖：

- 进入终端默认隐藏应用壳，退出全屏后恢复。
- 路径输入回车跳转；失败时保留旧路径。
- 多选文件创建多个任务，最多 3 个并发并显示进度。
- 取消单项、取消全部、切换主机和页面卸载会中止请求。
- 下载使用响应文件名并在失败时提示。
- 主节点 Token 不回显，空白保存表示保留。

最终验收执行：

- API 全量 Pytest、Ruff 和 mypy。
- UI 全量 Vitest、TypeScript、ESLint 和生产构建。
