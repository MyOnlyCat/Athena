# Athena 前端页面样式规范

本规范适用于 Athena-Node 与 Athena-Master。两个应用保持独立项目结构，但复用相同的
Ant Design 主题令牌、CSS 变量、登录布局、侧栏宽度和响应式断点。

## 设计原则

界面采用深色运维控制台风格：信息密度适中、状态优先、危险操作明确。页面主体使用
卡片和细边框组织，Web SSH 保持左侧服务器、中间终端、右侧文件的固定心智模型。

## 颜色

| 用途 | 深色 | 浅色 |
|---|---|---|
| 页面背景 | `#0B1020` | `#F4F7FB` |
| 导航/面板背景 | `#121A2B` | `#FFFFFF` |
| 次级面板 | `#111A2C` / `#101827` | `#F7F9FC` / `#EEF3F9` |
| 主文字 | `#F3F6FB` | `#172033` |
| 次文字 | `#B4C0D2` | `#526078` |
| 边框 | `#31415D` / `#24324A` | `#CBD5E1` / `#D9E1EB` |
| 品牌/主操作 | `#5B8CFF` | `#5B8CFF` |
| 成功 | `#1FA980` | `#1FA980` |
| 警告 | `#D99A16` | `#D99A16` |
| 错误/危险 | `#FF7A88` | `#D9363E` |
| 终端背景 | `#070B12` | `#070B12` |

正文对比度至少满足 WCAG AA。状态不能只依赖颜色，同时显示文字或图标。

## 排版和间距

- 中文与界面文字使用系统无衬线字体；IP、路径、哈希、命令使用等宽字体。
- 常规页面标题 30 px，卡片标题 16–17 px，正文默认使用 Ant Design 14 px，
  辅助信息 10–12 px。登录品牌标题是允许使用 44–76 px 的展示性例外。
- 以 4 px 为基础单位，常用间距为 8、12、16、24 px。
- 控件基础圆角为 8 px；品牌标记、内容卡片和登录卡片可分别使用 11、12、16 px。
  按钮和输入框高度 32–40 px；焦点态必须可见。

## 布局

- 桌面端侧栏 224 px；应用最小支持宽度为 320 px。内容区使用弹性宽度，不设置会导致
  小屏横向溢出的 960 px 硬下限。
- Web SSH：服务器列 240 px，中间终端弹性宽度，文件列 320 px。
- 登录页在 1050 px 以下切换为单栏。小于 1100 px 时文件列可折叠；小于 768 px
  时隐藏桌面侧栏，业务三栏页面改为抽屉或顺序导航。
- 表格操作保持右对齐；删除、禁用、重置密码需要二次确认。

新增页面应复用各应用 `ui/src/styles/global.css` 中的同名变量和 `theme.ts` 中一致的
Ant Design 主题令牌，不要在组件内引入新的近似颜色。主题基线变更时必须同步更新
Node、Master 与本文档。
