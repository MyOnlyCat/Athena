# Athena-Node 页面样式规范

## 设计原则

界面采用深色运维控制台风格：信息密度适中、状态优先、危险操作明确。页面主体使用
卡片和细边框组织，Web SSH 保持左侧服务器、中间终端、右侧文件的固定心智模型。

## 颜色

| 用途 | 色值 |
|---|---|
| 页面背景 | `#08111F` |
| 导航/面板背景 | `#0D1828` / `#111E30` |
| 悬浮面板 | `#17263A` |
| 主文字 | `#E6EDF7` |
| 次文字 | `#91A3BA` |
| 边框 | `#23344B` |
| 品牌/主操作 | `#36CFC9` |
| 链接/信息 | `#4096FF` |
| 成功 | `#52C41A` |
| 警告 | `#FAAD14` |
| 错误/危险 | `#FF4D4F` |
| 终端背景 | `#050A12` |

正文对比度至少满足 WCAG AA。状态不能只依赖颜色，同时显示文字或图标。

## 排版和间距

- 中文与界面文字使用系统无衬线字体；IP、路径、哈希、命令使用等宽字体。
- 页面标题 24 px，卡片标题 16 px，正文 14 px，辅助信息 12 px。
- 以 4 px 为基础单位，常用间距为 8、12、16、24 px。
- 圆角 8 px；按钮和输入框高度 32–40 px；焦点态必须可见。

## 布局

- 桌面端侧栏 224 px；内容区域最小宽度 960 px。
- Web SSH：服务器列 240 px，中间终端弹性宽度，文件列 320 px。
- 小于 1100 px 时文件列可折叠；小于 768 px 时三栏改为抽屉切换。
- 表格操作保持右对齐；删除、禁用、重置密码需要二次确认。

新增页面应复用 `ui/src/styles/global.css` 中的变量和 Ant Design 主题令牌，
不要在组件内引入新的近似颜色。
